# 🎮 Calculator

> 🧮 Простой интерактивный калькулятор в терминале. Мой первый шаг в C++ и геймдев.

---

## 📖 О проекте

**Calculator** это консольный калькулятор, который принимает два числа и символ действия (`+ - * /`), а затем выводит результат прямо в терминал.

Проект написан с нуля как **первый шаг в изучении C++** и пути в геймдев-разработку. Да, это не движок, не рендер, не физика. Но именно с таких маленьких кирпичиков строятся большие игры.

**Фишки:**
- 🎨 ASCII-меню в стиле старых терминальных RPG
- 🌍 Две версии: 🇷🇺 Russian и 🇬🇧 English
- 🛡️ Защита от деления на ноль
- 🧠 Чистый код без магии и внешних библиотек

## 🚀 Быстрый старт

### 🛠️ Что нужно

- **Linux** (тестировалось на Arch Linux)
- **Компилятор g++** - установка:
  ```bash
  sudo pacman -S gcc
  ```

### 📦 Установка

1. Скачай исходник `.cpp` со страницы **последнего релиза** (кнопка Releases справа).
2. Открой терминал в папке с файлом.

### ▶️ Компиляция и запуск

**🇷🇺 Русская версия:**
```bash
g++ calculator_ru.cpp -o calc_ru && ./calc_ru
```

**🇬🇧 English version:**
```bash
g++ calculator_en.cpp -o calc_en && ./calc_en
```

Готово. Калькулятор ждёт твоего ввода. 🎯

## 🐛 Troubleshooting

Столкнулся с ошибкой? Возможно, она уже разобрана ниже.

### ❌ `g++: command not found`

**Причина:** компилятор не установлен.

**Решение:**
```bash
sudo pacman -S gcc
```
На Debian/Ubuntu:
```bash
sudo apt install g++
```

---

### ❌ `No such file or directory: calculator_ru.cpp`

**Причина:** терминал открыт не в той папке, где лежит файл.

**Решение:** перейди в нужную папку:
```bash
cd ~/путь/до/папки/с/проектом
ls  # проверь, что .cpp файл на месте
```

---

### ❌ `bash: ./calc_ru: Permission denied`

**Причина:** у бинарника нет прав на выполнение (редко, но бывает).

**Решение:**
```bash
chmod +x calc_ru
./calc_ru
```

---

### ⚠️ Калькулятор выдаёт странный результат или зависает

**Причина:** вместо числа ты ввёл буквы или символы. `std::cin` в таком случае оставляет переменную в сломанном состоянии.

**Решение:** перезапусти программу и вводи **только числа**. Проверка некорректного ввода в roadmap. 🛠️
